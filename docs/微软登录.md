# 微软正版登录的 Client ID

微软正版登录走的是 OAuth 2.0 设备代码流程（启动器显示一串代码，你在浏览器里输入）。
这一步需要一个 **Azure 应用的 Client ID**，并且这个 ID 要被 Mojang 批准访问 Minecraft API。

## 为什么启动器不内置一个？

一个启动器内置一个 ID，等于所有用户共用一个开关：这个 ID 被撤销，所有人同时不能正版登录。
所以 Block Launcher 默认留空，由**发行版的发布者**或**用户自己**填写：

- 发布者：申请一个 ID，写进 `src/BlockLauncher/Branding.cs` 的 `DefaultMicrosoftClientId` 再编译，用户开箱即用；
- 用户：在 **设置 → 账户** 里填自己的 ID，优先级高于内置值。

不同发行版、不同用户用不同的 ID，一个出问题不会连累别人。

> 请不要填其他启动器或官方启动器的 Client ID —— 那违反微软的使用条款，也随时可能失效。

## 申请步骤

**两个要用到的网址**

| 用途 | 地址 |
|---|---|
| 注册 Azure 应用、拿 Client ID | <https://entra.microsoft.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade><br>（或 <https://portal.azure.com> → Microsoft Entra ID → 应用注册） |
| 向 Mojang 申请 Minecraft API 权限 | <https://aka.ms/mce-reviewappid>（会跳到 Microsoft Forms） |

1. 打开 Azure 门户 → **Microsoft Entra ID → 应用注册 → 新注册**
   - 名称随意（例如 `BlockLauncher-你的名字`）
   - 支持的账户类型：**仅个人 Microsoft 账户**（或“任何组织目录中的帐户和个人 Microsoft 帐户”）
   - 重定向 URI 可以不填
2. 注册完成后，在应用的 **身份验证** 页面，把 **允许公共客户端流** 设为 **是**，保存。
3. 在 **概述** 页复制 **应用程序(客户端) ID**。
4. 到 Mojang 的申请页面（在 Minecraft 帮助中心搜索 “Minecraft API access for third-party launchers / AppID review”）提交这个 Client ID，说明是第三方启动器，等待审核邮件。审核一般需要几天到几周。→ 直接打开 <https://aka.ms/mce-reviewappid>
5. 审核通过后，把 Client ID 填进 **设置 → 账户 → 微软登录 Client ID**。

> **重新申请时（旧 ID 被拒、被撤销，或想换名字）**
>
> - 表单第 4 栏 **Application Name 必须与 Azure 应用的显示名逐字一致**，建议统一成 `BlockLauncher-你的名字`；
> - 第 5 栏 Application ID、第 6 栏 Tenant ID 都要填**新应用**的值，别抄旧材料里的；
> - 第 7 栏 Associated website 填本项目仓库地址 <https://github.com/xiaojiubuchiyao/BlockLauncher>（能点开、能看到这是什么产品），比旧站页面更妥当；
> - Justification 正文最后一句的源码地址同样换成这个仓库地址。
>
> 逐栏填法与英文正文模板见同目录 `微软登录申请材料.md`。

## 没有 Client ID 时还能玩吗？

可以：

- **离线账号**：单人游戏、局域网、离线模式服务器；
- **外置登录**（authlib-injector）：LittleSkin、Blessing Skin 等皮肤站，有正版般的皮肤和多人体验；
- 拿到 ID 之后再添加微软账号，原有存档不受影响。

## 常见错误

| 提示 | 原因 |
|---|---|
| Client ID 无效 | ID 填错，或应用没开“允许公共客户端流” |
| 该应用无权访问 Minecraft 服务 | ID 还没通过 Mojang 审核 |
| 该微软账号没有 Xbox 账户 | 先去 xbox.com 用这个账号登录一次 |
| 未成年账号需加入家庭组 | 在 Microsoft 家庭组里由家长允许 |
| 该账号没有购买 Minecraft Java 版 | 账号里没有 Java 版授权 |
