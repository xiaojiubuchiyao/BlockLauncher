Block Launcher

去中心化的 Minecraft 启动器。单个 exe，没有服务器，不收集任何数据。

↓  下载 BlockLauncher.exe 查看源码

当前版本 v0.2.2 · 857 KB · Windows 10 / 11 双击即用，无需安装 .NET

它是什么

一个能长期自己活下去的启动器，而不是又一个需要服务器养着的客户端。

📦

单个 exe，拷走就能用

不需要安装、不需要运行库、不写注册表。整个文件夹复制到别的电脑，配置和存档一起带走。

🌐

没有后端

游戏、加载器、Mod 全部从官方源和公益镜像直连获取，版本列表实时拉取，启动器里不内置任何版本号。

🔏

更新靠签名清单

任何人都能镜像分发更新清单，只有签名对得上才会安装。维护者失联时，社区可以换钥匙接手。

🔐

不收集数据

没有统计、没有账号体系、没有云端。令牌用 Windows DPAPI 加密，只存在你这台电脑上。

🧩

整合包拖进去就装

支持 .mrpack / .zip，也支持没有清单的「绿色整合包」。每个整合包各用一个独立目录，删文件夹即卸载干净。

🛠️

崩溃能看出原因

自动识别内存不足、Java 版本不对、缺前置、重复 Mod、Mixin 冲突、显卡驱动等常见问题并给出建议。

三步开始

不用配置任何东西。

下载

点上面的按钮，拿到 BlockLauncher.exe。

放进空文件夹

双击运行。游戏文件会放在 exe 旁边的 .minecraft，配置在同级的 Block Launcher 文件夹。

选版本，启动

下载页挑正式版或整合包；也可以「添加已有的游戏目录」，直接接管官方启动器 / PCL / HMCL 的 .minecraft。
